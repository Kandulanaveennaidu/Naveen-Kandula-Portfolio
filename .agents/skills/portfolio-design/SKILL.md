# Portfolio Design Principles for Naveen Kandula

## 1. Visual Language
- **Dark + Minimal + Editorial + Futuristic + Technical**
- Primary Background: `#08090B`
- Secondary Background: `#0E1014`
- Card Background: `#12151A`
- Elevated Card: `#171A21`
- Accent Violet: `#7C5CFF`
- Accent Cyan: `#22D3EE`
- Success Emerald: `#22C55E`
- Subtle Borders: `rgba(255, 255, 255, 0.08)`

## 2. Typography Rules
- Use Inter / Geist for crisp readability.
- Use JetBrains Mono for system metrics, architecture labels, and code tokens.
- Generous line height (1.6 to 1.75) for body copy.
- No gigantic wall of text; use short, punchy editorial paragraphs.

## 3. Anti-Generic Guardrails
- NEVER use fake numbers, fake clients, fake testimonials, or fake awards.
- NEVER use skill percentage bars or cartoonish floating blobs.
- Always communicate *business problem solved* and *architectural solution* rather than just a dry list of tools.
